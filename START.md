# Install hk-auto-apply

You are installing a Grok Bot skill from https://github.com/PoetCoderJun/hk-auto-apply

1. Read `skill/hk-auto-apply/SKILL.md`.
2. Save the entire `skill/hk-auto-apply` directory into the skill library, including `references/` and `scripts/`. Do not save only the `SKILL.md` text.
3. Keep the name and description from that `SKILL.md` unchanged.
4. After it is saved, follow `skill/hk-auto-apply/references/intake.md`: tell the user what files, facts, and preferences they still need to provide. Do not start searching or applying yet.
5. Never ask for JobsDB or LinkedIn passwords.
6. Do not copy anyone else's resume, salary, visa, or screening rules into this install. Wait for the current user's materials.
