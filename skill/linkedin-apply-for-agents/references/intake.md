# 安装与收集资料

用户说「请安装这个 GitHub 链接」并贴了本仓库（包括仍会跳转过来的旧地址 https://github.com/PoetCoderJun/hk-auto-apply），或提到旧技能名 `hk-auto-apply` 时：读取 `skill/linkedin-apply-for-agents/SKILL.md`，按原文名称和描述保存，同时把整个 `skill/linkedin-apply-for-agents` 目录（含 `references/`、`scripts/`）放进技能库。不要只保存 `skill/hk-auto-apply` 别名目录。保存成功后，马上把下面清单告诉用户，请他们按「文件 / 信息 / 偏好」一起提供；不要只说「把简历和范围发我」就等待。

用户说「开始投」「海投」或已经装好本技能时，也用同一份清单核对，缺什么补什么。

## 要请用户提供什么

**文件（必须）**

1. 简历文件：PDF 或 Word
2. 岗位范围：打出来的文字，或一份选岗说明文档。要足够解读出：优先投什么、可以考虑什么、硬性排除什么、哪些只是软性提示（仍可投，但要在备注里写上）

**信息（简历或岗位范围里已有的不要再问）**

- 姓名、联系电话、申请用邮箱（通常写在简历上）
- 投递地区（必须，一开始就要确认。简历或岗位范围里已经写清的，不要再问）。确认后告诉用户将使用的平台，但不要让他们选择平台：一律投 LinkedIn；地区是香港时，自动同时投 JobsDB，并使用 LinkedIn 香港 `geoId=103291313`
- 该地区的工作身份或签证情况（在香港求职时，问香港工作身份或签证）
- 期望薪资及币种（要填年薪或月薪时按申请表要求换算）
- 预计可入职时间
- 语言能力以简历为准；没写的语种不要写成会

**偏好（必须问清，或用户已经说明过的可以不再问）**

- 不要询问要投哪些平台，也不要把「是否同时投 JobsDB」列入清单。平台只由已确认的投递地区决定
- 符合选岗规则且能投的岗位：是直接投，还是先准备名单再让用户确认
- 没有站内 Easy Apply / Quick Apply、要去公司自己申请页时：默认「海王模式」（简单就填，复杂就跳过，不要纠结）；也可以改成「一家都不能放过」（每家外部页都尽量跟完，更慢、更容易出错）。没说就按海王模式，不要当成缺失去追问
- 跟踪表放在哪里：本地 Excel、Google 表格、飞书、Notion，或用户指定的其他表。没说就默认生成本地 Excel，并告诉用户可以再导出或迁走
- 是否需要一份可分享的只读副本（未说就保持私有）
- 仅当投递地区是香港、因而会自动投 JobsDB 时，才问这些：JobsDB 职业分类按简历和选岗范围选最接近的一项，拿不准再问一次；若需要注册，用用户允许的 bot 信箱，还是用户指定的邮箱，不要擅自用他们的私人邮箱
- 这次投递跑在哪里：bot 的云电脑，还是用户自己的电脑
- 日常增量检查希望在几点跑（用户自己的时区）。没说可默认工作日早上大约 9:00，但要告诉用户可以改，并让他们确认

不要向用户索要 LinkedIn 或 JobsDB 的登录密码，也不要把密码列入收集清单。登录在实际使用的那台电脑上完成：用户可以自行接管这台电脑，自己登录；也可以让助手在这台电脑的浏览器里走登录流程。

若用户选择自己的电脑：使用期间以及定时任务触发时，那台电脑要开机并保持在线。把这一点连同他们选定的定时时间一并说清楚。

## 用户交来了但有缺失时

1. 对照上面的文件、信息、偏好三类清单逐项核对。先读简历和选岗说明，能提取的就不要再问。
2. 只追问仍然缺少的项。一次说清还缺什么，不要把已经提供的再问一遍，也不要泛泛说「请补充更多信息」。
3. 下面这些算缺失，必须追问并等用户补齐：简历文件没有或打不开；没有岗位范围，或范围太笼统，形不成「优先 / 可考虑 / 硬性排除 / 软性提示」；投递地区仍不清楚；没说是直接投还是先确认；没说跑在云电脑还是自己的电脑；该地区工作身份、期望薪资或可入职时间仍然不清。不要把「要投哪些平台」或「是否同时投 JobsDB」当成缺失项去追问。日常定时任务的时间若用户说首轮后再设，可以等到设任务时再确认；若选了自己的电脑，设任务时必须提醒他们到点要开机。不要把登录密码当成缺失项去追问。
4. 必须项未齐之前，不要开始搜岗或投递。投递地区未确认前，尤其不要开始。
5. 用户补了一部分之后，再核对一遍；还缺就继续只问剩下的。全部齐了，用几句话复述你读到的候选人、投递地区、将使用的平台（由地区决定）、优先方向和硬性排除项，然后开始。

把岗位范围解读成可执行的选岗规则时，用户这份说明是唯一标准。用户已经交齐必须材料，并表达要自动海投、安装本技能后开始，或说「符合要求就直接投」时，视为已授权对符合选岗规则且能投的岗位直接投递，不要逐岗再问。如果他们只是在问怎么用、还没交材料，就先把清单发出去。
